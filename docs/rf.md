# Requisitos Funcionais

### RF01 - Geração de E-mails com IA:
O sistema deve integrar-se à API da OpenAI para gerar templates de e-mails de
prospecção hiper-personalizados.

### RF02 - Enriquecimento de Dados 
O sistema deve possuir uma funcionalidade de enriquecimento de dados, coletando e
validando razão social, CNAE e endereços via Brasil API a partir de um CNPJ informado.

### RF03 - Exportabilidade de Dados
O sistema deve permitir a exportação dos dados cadastrais tratados em planilhas
formatadas no formato .csv.

### RF04 - Cálculo de Frete 
O sistema deve disponibilizar uma calculadora dinâmica web que calcule orçamentos
logísticos instantâneos a partir do cruzamento de múltiplos CEPs.

### RF05 - Pipeline Interativo
O sistema deve apresentar um Pipeline Interativo para gerenciamento
do hub das funções comerciais

### RF06: Gráficos Pesquisa de Satisfação
O sistema deve renderizar gráficos dinâmicos de Customer Experience alimentados
por relatórios da SoluCX (CSAT e NPS).
